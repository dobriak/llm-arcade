This folder will contain a set of coding abilities quality measurement tests for locally hosted LLMs. The first test application I would like to measure against is a typical Kanban dashboard with a local sqlite as the backend storage. Can you write a general product requirement document in kanban-board/PRD.md and a specialized set if instructions in each of the subdirectories, they are named after the backend - frontend pair I would like the LLM to choose: FastAPI with Htmx, NestJS with ReactJS, Gin with SvelteKit. For example, kanban-board/fastapi-htmx/TECH.md should contain detailed technical instructions on how to set up the latest stable versions of FastAPI, Htmx and the most popular ORM (in this case Alembic) backed by sqlite. All implementations of those instructions should be able to create their own set of Docker images and a docker-compose.yaml that can spin up the solution from scratch. The implementations will be under kanban-dashboard/<backend>-<frontend>/<Local LLM name>
